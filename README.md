# 스터디 홈페이지 구현

📚 스터디 커뮤니티 및 통계 홈페이지
이 프로젝트는 스터디 목표를 효율적으로 관리하고, 사용자 간 커뮤니티를 형성하며, 학습 데이터를 시각화하는 웹 기반 솔루션입니다. 할 일 관리, 그룹 스터디, 소셜 네트워킹 기능이 결합되어 사용자들의 학습 동기를 높이고 성과를 체계적으로 관리할 수 있도록 돕습니다.

🔹 주요 기능

📝 스터디 관리

- TO-DO List: 할 일 목록 생성 및 관리
  개인별/그룹별 목표 설정 가능
  진행 상황, 마감 시간, 우선순위 관리
- 스터디 그룹: 스터디 그룹 개설 및 참여
  그룹 내 TO-DO 공유
  멤버 간 목표 달성 협력
- 스터디 통계: 완료된 TO-DO List 시각화
  그래프로 학습 패턴 및 성취도 확인

💬 커뮤니티 및 소셜 기능

-게시판: 모든 사용자가 소통 가능
 글 작성, 수정, 삭제, 조회, 좋아요 및 스크랩 기능 지원
-댓글: 게시글에 자유롭게 의견 공유
-공지사항: 관리자가 공지를 게시하여 사용자에게 알림

👤 사용자 관리 및 편의 기능

-회원 시스템: 회원가입, 로그인, 비밀번호 찾기, 개인정보 수정, 회원 탈퇴
-알림 기능: 새로운 게시글 및 공지 알림
-검색 기능: 게시글, 사용자, 카테고리 등 다양한 항목 검색 가능

🖥 화면 구성

1. 공부 : 오늘의 TO-DO 및 스터디 통계 그래프

2. 스터디 : 그룹 개설, 참여, 멤버 관리

3. 커뮤니티: 글 작성/조회/댓글/좋아요/스크랩

4. 마이페이지: 로그인/회원가입/프로필 수정

5. 캘린더: 완료된 TO-DO  캘린더로 시각화 및 학습 패턴 분석

| ----- | ------------------------------- |

| 프론트엔드 | JSP, HTML, CSS, JavaScript      |
| DB    | Oracle / MySQL                  |
| 시각화   | Chart.js / D3.js                |
